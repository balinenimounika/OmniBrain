Project 3 - "SwarmRL": Multi-Agent Deep Reinforcement Learning Simulator 
Domain: Autonomous Systems & Deep Reinforcement Learning 
Problem Statement: Training a single agent to navigate an environment is well understood. However, 
coordinating a swarm of 50 autonomous agents to search a disaster zone dynamically without 
colliding—optimizing their coverage area collectively—is highly complex and fails with standard 
pathfinding algorithms. 
Use Case: A disaster response coordinator uses SwarmRL to deploy simulated search drones. The 
backend uses Ray RLlib to run a Multi-Agent Proximal Policy Optimization (MAPPO) algorithm. The 
agents learn to collaborate in a decentralized manner, sharing spatial rewards to maximize the search 
area covered while heavily penalizing mid-air collisions. The React and WebGL dashboard renders the 
trained swarm executing a flawless, emergent search pattern in a 3D environment.
