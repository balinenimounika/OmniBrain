Project 1 - "OmniBrain": Agentic Multi-Modal RAG Orchestrator 
Domain: Large Language Models (LLMs) & Agentic AI 
Problem Statement: Standard Retrieval-Augmented Generation (RAG) pipelines fail when documents 
contain complex multimodal data (like financial tables, embedded charts, and images) or when queries 
require multi-step reasoning across diverse data silos. 
Use Case: A quantitative analyst feeds a 500-page corporate financial PDF into OmniBrain. Using a 
LangGraph supervisor agent, the system dynamically routes tasks. It parses tables using a Vision-
Language Model (VLM), queries a vector database for semantic text, and uses a Text-to-SQL agent to 
query historical stock data [1.2.2]. The agents collaboratively synthesize the findings and output a highly 
accurate, cited investment memo, completely bypassing the hallucination risks of standard LLMs. 
Key Modules: 
• 
Agentic Orchestrator (LangGraph): Manages the state, memory, and routing of multiple 
specialized AI agents (Search Agent, SQL Agent, Vision Agent) [1.2.2]. 
• 
Multi-Modal Retrieval (Qdrant / FAISS): Stores both text chunks and image embeddings (using 
CLIP) for semantic similarity search. 
• 
Vision-Language Model (GPT-4o / LLaVA): Extracts and reasons over visual charts and graphs 
embedded within the documents. 
• 
Evaluation & Guardrails (Langfuse & NeMo Guardrails): Monitors the LLM outputs for toxicity, 
hallucinations, and ensures responses are strictly grounded in the retrieved context [1.2.2].
